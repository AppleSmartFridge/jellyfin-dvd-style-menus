# Disc Menus 1.0.0

> [!WARNING]
> **This entire project was vibecoded.** It was written by prompting an AI model, not by hand, and has not been tested end-to-end against real discs or real Jellyfin clients. Treat this release as experimental and expect bugs.

The first release of Disc Menus: a Jellyfin plugin that plays **decrypted** Blu-ray ISOs and BDMV folders **with their menus**, both HDMV and BD-J (Java) menus.

## Requirements

- Jellyfin **12.1 or newer**
- Optional: the **File Transformation** plugin, for the Disc Remote button in the web player

## What's included

**Disc menus on any client.** The server plays the disc and draws the menus into a live video stream. Each Blu-ray gets a **Disc Menu (Interactive)** version, and Jellyfin streams it to whatever client you use. No client changes are needed.

**Ways to navigate the menus.**
- **Disc Remote button in the web player** (browsers, Jellyfin Media Player/Desktop, and the Android and iOS apps that wrap the web client). It opens an on-screen remote, with the phone remote offered inside it.
- **Disc Remote page** in the Jellyfin side menu.
- **Phone remote:** scan a QR code, or open the link shown under it. Works with every client, including native TV apps.
- **Keyboard** (optional): arrow keys and Enter go straight to the menu.

**Plain versions with seeking.** Each disc also gets **Main Feature** and extras versions. These play on every client with no menu, and you can seek in them.

**Library details from the disc.** Runtime and chapters are read from the main feature, including for ISOs.

**Nothing to install on the server.** The plugin downloads the runtime for your platform on first use and checks its SHA-256 before using it. An offline package with every runtime included is also available.

## Downloads

| File | Use it when |
|---|---|
| `discmenus_1.0.0.0.zip` | Normal install. The runtime downloads on first use. |
| `discmenus_1.0.0.0_offline.zip` | The server has no internet access. Includes every platform's runtime. |
| `bdmenu-runtime-<platform>.zip` | Installing a runtime by hand (Settings → Runtime → local folder). |
| `manifest.json` | Jellyfin plugin repository manifest. |

Runtime platforms: `linux-x64`, `linux-arm64`, `linux-musl-x64`, `win-x64`, `osx-arm64`.

## Install

Add this repository in **Dashboard → Plugins → Repositories**, install **Disc Menus**, and restart Jellyfin:

```
https://github.com/AppleSmartFridge/jellyfin-dvd-style-menus/releases/latest/download/manifest.json
```

Or unzip `discmenus_1.0.0.0.zip` into `<config>/plugins/DiscMenus_1.0.0.0/` and restart.

## Known limitations

- **Decrypted discs only.** Encrypted discs are detected and not offered.
- **No Intel Mac runtime** in this release.
- **Native clients** (Android TV, Moonfin, TV apps, Swiftfin) need the phone remote, or the "press Enter automatically" setting, to move through menus.
- **Menu playback is a live re-encode** on the server, so it uses CPU or GPU like a transcode. A button press takes about 1–2 seconds to show on screen.
- **No seeking in the menu version.** Use the chapter buttons, or play the Main Feature version.
- Title versions play angle 1 only and don't trim in/out points inside a clip.
- BD-Live and other online BD-J features aren't supported.
- Unusual ISO images may not be recognised. BDMV folders always work.

## Reporting problems

Please open an issue with your Jellyfin version, server OS, client, and whether the disc is a folder or an ISO. Include the output of **Dashboard → Plugins → Disc Menus → Status** and any `Disc Menus` / `bdmenu` lines from the Jellyfin log.
