Disc Menus

Plays decrypted Blu-ray ISOs and BDMV folders with their HDMV and BD-J menus. The menus run on this server and reach clients as ordinary video, so every client can show them. Navigate with the Disc Remote: the remote button in the web player, the Disc Remote page in the menu, or your phone.

Web client

Opens an on-screen remote. Needs the File Transformation plugin (or any script injector) so the script loads in jellyfin-web.
Arrow keys, Enter, digits, F1–F4 (colours), PageUp/PageDown (chapters), Home (top menu) and End (pop-up), only while a disc menu is playing.
